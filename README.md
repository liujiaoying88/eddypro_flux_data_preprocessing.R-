# Eddy Covariance Flux Analysis

## Project Overview

This repository contains a complete Eddy Covariance flux analysis workflow for ecosystem carbon flux research.

The workflow includes:

* Flux data preprocessing
* Timestamp conversion
* Invalid value filtering
* Missing value checking
* CO₂ flux time-series visualization
* Daily aggregation analysis
* Figure export
* Daily dataset generation

## Programming Language

* R
* tidyverse
* lubridate

## Workflow Structure

```text
scripts/
│
├── 01_flux_preprocessing.R
├── 02_timestamp_processing.R
├── 03_flux_analysis_workflow.R
```

## Outputs

* Full-year CO₂ flux time series
* Daily mean flux figures
* Aggregated daily dataset
